# Flow Linking Ontology of Wonders (FLOW)

Description: Ontology for describing fluid flow through functional locations in transformation industry installations.

More information can be found at http://obofoundry.org/ontology/flow

## Versions

### Stable release versions

The latest version of the ontology can always be found at:

https://www.inf.ufrgs.br/ontologies/flow.owl

(note this will not show up until the request has been approved by obofoundry.org)

### Editors' version

Editors of this ontology should use the edit version, [src/ontology/flow-edit.owl](src/ontology/flow-edit.owl)

## Contact

Please use this GitHub repository's [Issue tracker](https://github.com/INF-UFRGS-Ontologies/FLOW/issues) to request new terms/classes or report errors or specific concerns related to the ontology.
